# 第三方依赖

源码通过 Gradle 引用以下上游组件。版权、许可及适用条款以各组件随附的文件与上游项目为准；本项目未修改这些组件。

| 组件 | 上游 |
| --- | --- |
| AndroidX / Jetpack Compose | https://android.googlesource.com/platform/frameworks/support/ |
| Google Material Icons | https://github.com/google/material-design-icons |
| AndroidSVG | https://github.com/BigBadaboom/androidsvg |
| Google Play Services Auth | https://developers.google.com/android/guides/overview |
| Dropbox Java SDK | https://github.com/dropbox/dropbox-sdk-java |
| jcifs-ng | https://github.com/AgNO3/jcifs-ng |
| MinIO Java SDK | https://github.com/minio/minio-java |
| StAX API | https://mvnrepository.com/artifact/javax.xml.stream/stax-api |
| Woodstox | https://github.com/FasterXML/woodstox |
| JUnit 4 | https://github.com/junit-team/junit4 |
| org.json（仅测试） | https://github.com/stleary/JSON-java |

公开发布和分发前应保留相关许可证、声明，并核对二进制分发要求。
